# WMC_projekt_MFKK
## We want to create a website about spaceflight companies.

This project now uses a JSON data source for the company pages instead of many static HTML files.

### Start the project
1. Install dependencies: `npm install`
2. Start the JSON API: `npm run json-server`
3. Open the site with a static server (for example `npm start`) and navigate to `http://127.0.0.1:8080/index.html`

The new single company page is `company.html?id=<company-id>`.
